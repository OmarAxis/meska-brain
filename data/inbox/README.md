# Inbox (synthetic)

Every file here is made up by `meska_brain.synth`. The learners are aliases, the teachers are fictional, and nothing refers to a real child or school.

Each file is about the new term 2025-T1, which is not in the database yet, so the agent can ingest it as fresh evidence.

- `quiz_sheet_*.md`: item-level results, English markdown table
- `teacher_note_A17_sw.txt`: a short teacher note in Swahili
- `teacher_note_ar.txt`: a short teacher note in Arabic
- `register_*.csv`: attendance for three learners, with a blank value on purpose
